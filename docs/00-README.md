## The four things that govern everything

**1. AIMMI prepares the Vietnamese file. The destination is a variable.**
Source of funds is source of funds whether the file ends in Alberta, an EB-5 regional centre, or Panama. This is why adding two destinations required no new services.

**2. Readiness, never eligibility.**
AIMMI assesses whether a file is ready. Licensed representatives determine eligibility. One line, every destination, both languages, no exceptions.

**3. Nothing is published that is not verified and consented.**
The rebuild exists because the current site published a credential that does not exist and a representation claim that was never true. The clearance gate (doc 03 §3) makes this mechanical rather than remembered.

**4. Data the site never holds cannot leak, cannot be transferred, and cannot be demanded.**
Assessment answers never leave the browser. This is architecture, not policy.
